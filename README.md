# 🧾 XML Payroll WA Automation

This project automates the generation of payroll XML files using data from Excel, adapted for WA (Work Automation) systems.

## 📁 Files

- `excel_to_wapw.py`: Main Python script for converting Excel data into XML.
- `payroll_template.xlsx`: Input template for employee payroll data.
- `output_payroll.xml`: Sample output generated by the script.
- `XML_Payroll_Project_Presentation.pptx`: Presentation explaining the project.

## 🚀 How to Use

1. Fill the `payroll_template.xlsx` with the required data.
2. Run the Python script:
   ```bash
   python excel_to_wapw.py
