# 🧾 WA Prevailing Wage Payroll Automation

This project automates the generation of XML files for uploading payroll data to the WA Prevailing Wage system.

## 🚀 Features
- Fill out payroll data in Excel
- Run a Python script to generate XML
- Upload directly to the WA platform

## 🛠 Technologies
- Python 3
- pandas
- xml.etree.ElementTree
- Excel

## 📂 Files
- `payroll_template.xlsx`: Excel template to input payroll
- `excel_to_wapw.py`: Python script to generate XML
- `output_payroll.xml`: Sample XML output

## 👀 How to Use
1. Fill out the Excel file
2. Run the script:
   ```bash
   python excel_to_wapw.py
